# 🐾 AdotaPet

Sistema de gerenciamento de adoção de animais, desenvolvido em Portugol (VisuAlg) como projeto pessoal de aprendizado em lógica de programação.

## 📋 Sobre o projeto

O AdotaPet permite cadastrar animais disponíveis para adoção, consultar informações e registrar o processo de adoção junto com os dados do adotante.

O projeto foi construído do zero, com foco em compreender e aplicar os conceitos de lógica de programação na prática.

## ⚙️ Funcionalidades

- **Cadastrar animal:** registra nome, espécie, sexo, idade, vacinação, castração e disponibilidade para adoção, com validação de campos obrigatórios e tela de conferência antes de confirmar.
- **Listar animais:** exibe todos os animais cadastrados.
- **Procurar animal:** busca um animal pelo nome.
- **Mostrar disponíveis:** lista apenas os animais disponíveis para adoção.
- **Marcar como adotado:** altera o status do animal e registra os dados do adotante (nome, data de nascimento, contato, documento e endereço), com tela de conferência e edição.
- **Listar adotados:** mostra a ficha de cada animal adotado junto com a ficha do respectivo adotante.

## 🛠️ Tecnologias

- Portugol (VisuAlg)

## 🚀 Como executar

1. Baixe o [VisuAlg](http://www.apoioinformatica.inf.br/produtos/visualg/) (gratuito).
2. Abra o arquivo `ADOTAPET.ALG` no VisuAlg.
3. Clique em **Run (Executar)**.
